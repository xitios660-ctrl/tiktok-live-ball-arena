# Ball Arena — Visual Theme Tokens

Inspired by the cozy indie “Identidade Visual Ticulinho Games” Pinterest board  
(palette + typography language only — **not** an official Ticulinho product / logo).

Boards: `brand/ticulinho/board-1197ca.png`, `board-1200.jpg`

## Palette

| Token        | Hex       | Use |
|--------------|-----------|-----|
| charcoal     | `#1E1E1E` | Arena / admin background (chalkboard) |
| cream        | `#F7F3E7` | Primary HUD & body text |
| teal         | `#4DB6AC` | Accents, timer healthy, links |
| coral        | `#FF6B6B` | CTAs, kill feed, low HP, urgency |
| gold         | `#FFC857` | #1 crown, kills highlights, winner |
| lavender     | `#A78BFA` | Soft accents, gift/purple notes |
| sage         | `#9AD17D` | Healthy HP, success / OK |

## Typography

- **UI / HUD / Admin:** [Nunito](https://fonts.google.com/specimen/Nunito) (rounded, friendly)
- Weights: 600–800 for titles; 500–600 for body
- Fallback: `Nunito, system-ui, sans-serif`

## Mood

Cozy indie · dark chalkboard · glass cards with cream text · coral CTAs · gold for crowns/#1  
Hand-drawn accents: small stars ★, soft hearts ♡ (shapes only — no copied logo assets)
